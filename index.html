KIIT Transit

Live tracking for KIIT's campus buses and EV carts. Drivers' phones broadcast GPS, and students see every running vehicle on a campus map with ETAs, routes and schedules.

4 s GPS broadcast interval11 / 11 tests · 0 analyzer issuesStudent + driver apps
  • Student app: a live campus map (flutter_map with MapTiler/OpenStreetMap tiles), animated markers with heading arrows, EV/bus filters, ETAs, upcoming stops inferred from the vehicle's heading, route lines with per-stop ETAs, and schedules marked on time, delayed or cancelled.
  • Driver app: pick a vehicle, go on duty, and the phone broadcasts GPS every 4 seconds from an Android foreground service that keeps working with the screen off.
  • Crowd demand signals: stranded students tap where they're waiting. A Supabase RPC merges requests per location over 30 minutes, counts each student once and applies a 5-minute cooldown, so drivers see how many people are actually waiting.
  • Security in the database, not just the app: Row-Level Security policies mean a driver can claim only a vehicle nobody else is driving and update only their own, and a server-side trigger rejects any email outside @kiit.ac.in.
  • MVVM with repositories over a swappable data source (Supabase or a built-in simulator), so the whole app also runs as a realistic demo with no backend.

Systems · Sep 2026

BounceBlitz

A standalone email verification engine and desktop app that does what NeverBounce and Reoon do, with no SaaS APIs and no per-email bill.

50 parallel workers~150–300 ms per M365 checkPortable Windows .exe
  • A PySide6 desktop window wraps an embedded Flask microservice on a dynamic local port, so the whole tool ships as one portable .exe that verifies thousands of emails per minute.
  • Multithreaded engine (ThreadPoolExecutor) with dynamic MX resolution, backup-MX failover and SMTP RCPT TO probing, streaming CSVs in and results out with live progress.
  • Provider-aware heuristics avoid the Directory Harvest Attack blocks that enterprise gateways (Proofpoint, Mimecast) put up. Conservative phrase matching means a security-block 550 is never reported as a dead mailbox.
  • For Microsoft 365 domains, I found and integrated Microsoft's unauthenticated GetCredentialType endpoint. It answers over HTTPS, so there are no port-25 blocks or IP-reputation limits, and it costs nothing.
  • Detects headerless CSVs, and scores every address 0–100 using Reoon-style categories: valid · catch-all · unknown · invalid.

AI agent · Sep 2026

Bot Assistant

A local-first AI agent desktop app. A model running on your own machine can browse the web, work with files, run commands and handle Gmail, all inside guardrails.

20+ structured tools26 unit tests + live testsLocal model via Ollama
  • A custom agent loop in Rust: plan → pick a tool → execute → observe → re-plan. Stopping a run cancels any model or tool call still in flight.
  • Model-agnostic through a ModelProvider trait with an Ollama backend, with separate chat and tool models you can pick in the UI.
  • The model never gets raw control. It calls structured tools for the filesystem, terminal, browser and Gmail. The browser is a Playwright worker in Node with a persistent profile, one per app, restarting itself if it crashes.
  • Safety first: risk tiers are deny-by-default (unknown tools count as high-risk, and deleting files or trashing mail needs approval in the UI). The workspace sandbox blocks ../ path escapes, the terminal allowlist rejects chained shell operators, and web and email content is wrapped as untrusted to resist prompt injection.
  • Gmail over OAuth 2.0 with PKCE and state checks. Tokens are kept in the OS credential store, and headers are sanitised against CRLF injection.
  • Chat and tool history are saved in SQLite. Next up: agent profiles, memory, scheduling, vision/computer use and multi-agent orchestration.

IoT + TinyML · Mar 2026

Sign Language Recognition Glove

A gesture-controlled assistive glove that recognises sign-language letters on the microcontroller and speaks them aloud through a companion Flutter app.

A–Z letters with spoken audioUSB + Wi-FiOn-device inference

The glove

  • Self-made flex sensors on a glove plus an MPU6050 IMU capture finger bends and hand tilt in real time.
  • Trained a TinyML gesture model in Edge Impulse and deployed on-device inference on a Raspberry Pi Pico W.
  • A lightweight real-time pipeline with low-pass filtering and window averaging keeps detection stable and avoids false triggers. Gestures can also drive actuators for hands-free control.

Talking to the phone

  • A Python bridge script reads the recognised gesture from the device and broadcasts it over a WebSocket server (port 8765).
  • The Flutter companion app listens on that socket, shows the detected letter and plays its spoken sound, with custom audio for all 26 letters.
  • It connects over USB (through adb reverse) first, falls back to Wi-Fi automatically if that fails, and reconnects on its own if the link drops.
